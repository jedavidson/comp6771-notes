# Modern C++ for C programmers

The aim of these notes is to be a reference for modern C++ as someone who has a background in C and some standard topics in computer science (OOP, data structures and algorithms, concurrency).
You probably can't (and shouldn't) expect to learn C++ from these notes alone.

These notes evolved out of something I first made when I took [COMP6771 Advanced C++ Programming](https://www.handbook.unsw.edu.au/undergraduate/courses/2024/comp6771?year=2024), a course taught at UNSW.
You can still view these as concise reference material covering *most* of the lectures that also provides some interesting additional commentary on it, but do keep in mind that over time, I have added material beyond its scope (e.g. the entire section on concurrency).
